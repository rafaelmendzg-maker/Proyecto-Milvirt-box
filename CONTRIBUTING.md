# Contributing to Milvirt

## Git Flow adaptado

- `main`: rama de producción (protegida). Solo se recibe mediante Pull Request aprobados y con CI exitoso.
- **Ramas de trabajo**:
  - `feature(radar)`: agregar movimiento continuo de objetivos.
  - `fix(auth)`: resolver redirección post-login.
  - `docs(readme)`: agregar diagrama de arquitectura.
  - `chore(deps) `: actualizar dependencias de supabase.
## Conventional Commits

- **Bitacora de Cambios**:
### Added - para nuevas funcionalidades (feat).

### Fixed - para correcciones de errores (fix).

### Changed - para cambios en funcionalidades existentes (refactor, perf).

### Removed - para funcionalidades eliminadas.

### Security - para parches de seguridad.
